# 🎧 Yandex Music Downloader (Console)

[![Python](https://img.shields.io/badge/python-3.8%2B-blue)](https://www.python.org/)
[![License](https://img.shields.io/badge/license-MIT-green)](LICENSE)

Консольный менеджер для пакетной загрузки треков из плейлистов и альбомов Яндекс.Музыки.  
Работает в интерактивном режиме: вы указываете путь, добавляете ссылки на плейлисты/альбомы и запускаете скачивание одной командой.

> ⚠️ **Дисклеймер**  
> Проект использует неофициальное API и предназначен **только для личного ознакомления**.  
> Массовое автоматическое скачивание нарушает [условия использования Яндекс.Музыки](https://yandex.ru/legal/music_termsofuse/) и может привести к блокировке аккаунта.  
> Автор не несёт ответственности за возможные последствия.

## ✨ Что умеет

- 📂 Выбор и просмотр целевой папки для сохранения
- 📋 Пакетное добавление плейлистов и альбомов (можно несколько сразу через запятую)
- 📝 Просмотр текущей очереди на загрузку
- 🧹 Очистка очереди целиком или по типу (альбомы / плейлисты)
- 🚀 Загрузка всех треков из очереди одной командой
- 📜 Просмотр файлов в целевой папке

## 📦 Установка и настройка

1. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/VeterChul/Downloads_Music.git /opt/download_music
   cd /opt/download_music
   ```

2. **Установите зависимости**
   ```bash
   pip install prompt_toolkit yandex-music
   ```
   Основная библиотека: `yandex-music-api`

3. **Получите токен Яндекс.Музыки**  
   Программа автоматически выдаст инструкции по авторизации
   Или запустите скрипт create_key.py

## 🚀 Использование

Запустите программу:
```bash
python main.py
```
Вы увидите приглашение `>`. Вводите команды.

### Краткий пример работы
```
> sp C:\Users\Me\Music
Путь для установки изменён на C:\Users\Me\Music

> addplay "Хиты 2024", "Спокойная музыка"
Добавлены плейлисты: "Хиты 2024", "Спокойная музыка"
Можно устанавливать только ваши плейлиты. Вам предложится варианты из того, что у вас есть

> addalb "Новый альбом"
Добавлен альбом "Новый альбом"
Можно устанавливать только понравившиеся вам плейлисты. Вам предложится варианты из того, что у вас есть

> linst
Текущий список на установку:
  Плейлисты:
    - Хиты 2024 (21 трек)
    - Спокойная музыка (13 треков)
  Альбомы:
    - Новый альбом (10 треков)

> install
```

## ⌨️ Команды

### Работа с файлами
| Команда | Описание |
|---------|----------|
| `sp <путь>` | Выбрать папку для сохранения треков |
| `where` | Показать текущую папку сохранения |
| `ls` | Показать файлы в папке сохранения |

### Работа с альбомами и плейлистами
| Команда | Описание |
|---------|----------|
| `addplay <url1, url2, ...>` | Добавить один или несколько плейлистов (через запятую) в очередь |
| `addalb <url1, url2, ...>` | Добавить один или несколько альбомов (через запятую) в очередь |
| `linst` | Показать все добавленные альбомы и плейлисты |
| `cil [albums/playlists]` | Очистить очередь. Без аргументов — полностью, с аргументом — только альбомы или только плейлисты |
| `install` | Начать загрузку всех треков из очереди |

### Остальные
| Команда | Описание |
|---------|----------|
| `help` | Показать встроенную справку |
| `q` / `exit` | Выйти из программы |

## ⚠️ Важные замечания

- При добавлении нескольких альбомов/плейлистов разделяйте их запятой (с пробелом).
- `install` запускает последовательную загрузку **всех** треков из очереди. Убедитесь, что путь указан верно и достаточно места на диске.
